# DroidCare Website

Static GitHub Pages website for DroidCare.

## Setup
1. Replace `support@yourdomain.com` with your real support email.
2. Replace `YOUR-USERNAME` in `robots.txt` and `sitemap.xml`.
3. Add your actual DroidCare logo/screenshots under `assets/images/` if desired.
4. Update the Privacy Policy so it exactly matches the production Android app, permissions and third-party SDKs.
5. Push the repository to GitHub and enable GitHub Pages from Settings → Pages.

Pages:
- `index.html`
- `privacy-policy.html`
- `terms.html`
- `contact.html`
- `404.html`
